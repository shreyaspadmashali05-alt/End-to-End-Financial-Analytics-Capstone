# End-to-End Financial Analytics Capstone

A comprehensive data visualization and predictive modeling capstone project designed to showcase executive-level technical proficiency for the IT sector. This repository demonstrates the transformation of raw financial records into strategic business insights using Python, advanced Power BI dashboards, and a dynamic stakeholder presentation.

## 📌 Executive Summary
In today’s data-driven IT and enterprise landscape, the ability to clean raw data, predict future trends, and visualize key metrics is critical. This project serves as a complete workflow of a Data Analyst, moving from raw sales data to actionable business intelligence. 

The analysis processes over 700 records of global financial data, engineering features to calculate net profit margins, identifying regional sales trends, and deploying a regression model to forecast future segment performance.

## 🛠️ Tech Stack & Methodologies
* **Language & Libraries:** Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn)
* **Business Intelligence:** Power BI (DAX, Interactive Dashboards, Data Modeling)
* **Data Processing:** Excel (Initial formatting), Python (Cleaning, EDA, Standardization)
* **Core Skills Demonstrated:** Exploratory Data Analysis (EDA), Predictive Modeling (Linear Regression), Data Storytelling, Stakeholder Presentation.

## 📊 Key Insights & Business Value
1. **Profitability Baseline:** Successfully mapped and analyzed a baseline of $118.7M in net sales and $16.8M in net profit.
2. **Predictive Modeling:** Implemented a robust regression model to forecast unit sales based on historical manufacturing prices and segment trends.
3. **Strategic Recommendations:** Identified high-yield geographic regions and product lines, allowing stakeholders to allocate marketing and production budgets effectively.
